返回数据说明

Webhook 处理完成后会返回如下 JSON 格式数据，供推送方识别入库状态：

{
  "success": true,
  "id": "123",
  "target": "zinc0",
  "desc": "成功处理 1/1 条数据",
  "error": ""
}
字段 说明
success 入库状态，true 表示成功，false 表示失败
id 入库记录的 daily_prices 自增 ID；多条记录时用逗号分隔；失败时为空
target 对应的产品代码（如 zinc0）；多条记录时用逗号分隔
desc 处理结果描述，失败时与 error 内容一致
error 失败时的错误信息，成功时为空字符串

使用说明

1. 在企业微信群中添加「群机器人」，复制其 Webhook 地址填入推送配置。

2. 使用数据拼接工具选择 报价日期、产品名称、日均价、涨/跌 等字段，生成消息模板；可绑定多个产品，推送时每个产品各自渲染最新价格并拼接为一条消息。

3. 保存后系统生成专属推送地址，访问该地址（默认通过 ?key=密钥 验证）即向微信 Webhook 推送最新报价消息。

4. 可将该地址配置到「定时任务」或外部调度系统中，实现定时自动播报。
